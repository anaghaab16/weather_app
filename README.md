# Weather App

A Python script that fetches current weather data for a given city using the
[wttr.in](https://wttr.in) service and prints it to the console.

## Features
- Prompts the user for a city name
- Fetches a compact, one-line weather summary from wttr.in
- Handles failed requests with a basic error message

## Built With
- Python
- `requests`

## How to Run
```bash
python weather.py
```
Enter a city name when prompted.
